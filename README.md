# aazib-dev

Personal portfolio and lead-generation website for **Aazib Ali** (freelance web, mobile, and AI/LLM developer in Islamabad, Pakistan).

Built with **Next.js 16 (App Router, Turbopack)**, **React 19**, **TypeScript**, and **Tailwind CSS v4**.

## Commands

Use `pnpm` only:

```bash
pnpm dev                 # Start local dev server
pnpm lint                # Run ESLint
pnpm exec tsc --noEmit   # Run strict TypeScript check
pnpm build               # Production build (requires network for next/font/google)
```
